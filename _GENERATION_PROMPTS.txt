GOOGLE FLOW — CHARACTER REFERENCE SHEET PROMPTS
================================================================
Main cast only — 24 locked variants covering ~95% of the 330 scene
prompts. Side characters are handled by in-prompt description.

HOW TO USE
- Open Google Flow in IMAGE mode (not video).
- Paste one prompt. Generate 3-4 variants. Pick the most on-model one.
- Save the chosen image into the matching folder shown above each prompt.
- Aspect ratio: 1:1 (square) for reference sheets.
- If Flow drifts off-model, regenerate — do NOT accept a "close enough"
  image. A sloppy reference will poison every Midjourney frame that
  uses --cref against it.
