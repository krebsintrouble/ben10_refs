QUICK PROMPT TEMPLATE
================================================================
When you have all URLs filled in, your scene prompts will look
like this (for a scene with Ben + Vilgax in OS style):

/imagine prompt: [scene description with character names, actions,
setting, mood, lighting, camera angle from your original prompt
file] --cref URL_Ben_age URL_Vilgax --sref URL_OS_style_anchor
--cw 100 --ar 16:9 --v 6

Key flags:
  --cref     character reference URL(s), space-separated
  --sref     style reference URL
  --cw 100   max character weight (face + hair + outfit)
  --cw 0     face only (use for alien-form scenes)
  --ar 16:9  widescreen (matches your original prompts)
  --v 6      Midjourney v6 (or --v 7 if available)
