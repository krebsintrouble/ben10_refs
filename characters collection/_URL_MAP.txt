QUICK PROMPT TEMPLATE
================================================================
For a scene with Ben + Vilgax in OS style:

/imagine prompt: [scene description from your original prompt file]
--cref <Ben_age_URL> <Vilgax_URL>
--sref <OS_style_anchor_URL>
--cw 100 --ar 16:9 --v 6

Flags:
  --cref     character reference URL(s), space-separated
  --sref     style reference URL
  --cw 100   max character weight (face + hair + outfit)
  --cw 0     face only (use for alien-form scenes)
  --ar 16:9  widescreen
  --v 6      Midjourney v6 (or --v 7 if available)


================================================================
VERIFY BEFORE USING
================================================================
After uploading to GitHub, test ONE URL by pasting it into a
browser. You should see the image load directly (no GitHub
interface around it). If you see a 404 page, check:
  1. Is the repo Public, not Private?
  2. Is the branch really "main" and not "master"?
  3. Did you upload folders to the ROOT of the repo (not
     nested inside another "characters collection" folder)?
